## 现有缺陷与通过边界

Admin 的阿语 Licenses 状态汇总仍未通过，英文输出还夹带不必要的知识片段；本次没有改业务意图识别。Admin 六个旧测试失败涉及自然表述策略与一个恢复筛选答案的精确文本预期，修改前后结果相同。

Customer 的申请流程问法在英文与阿语下仍有证据路由差异：英文偏向仅能确认当前 Profile 申请，阿语提供一般知识流程。两端流式技术协议一致，不等于所有双语业务答案一致。本报告不把这些业务问题标记为通过。

## 流式契约

assistant.chunk 含 content、streamVersion、chunkIndex、streamMode，chunkIndex 从 0 递增，已发送内容只能追加。streamMode 为 guarded_generation 或 verified_projection。assistant.message 是持久化权威回答，标记 complete、partial、failed 或 cancelled；异常不覆盖已公开前缀。

Customer SSE 保持 token 数据为 JSON 字符串以保留换行与 Unicode，并增加 result 事件携带权威 content、streamVersion、streamStatus，随后发送 end [DONE]。原有客户端可继续读取 token。停止前先校验会话所有权，不能终止另一个账户或 Profile 的任务。
